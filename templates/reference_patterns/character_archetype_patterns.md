# 人物原型模式参考

## 主角原型

### 受辱逆袭型（玄幻/都市重生最常见）

**核心特征**
- 起点弱小，被所有人看不起
- 内心有强烈的自尊和不甘
- 有一个清晰的"为了什么而变强"的动力
- 聪明，但不是全知（有盲区）

**成长轨迹**
```
被动承受羞辱 → 获得机遇 → 主动反击 → 局部强大 → 更大舞台的新起点 → 循环
```

**弱点设计**（让主角不完美）
- 对某个人（家人/爱人）有情绪上的弱点
- 对某类人（曾经伤害过自己的人）有过度反应
- 某个能力盲区（需要弥补）

---

### 重生改命型（都市重生标配）

**核心特征**
- 经历过失败/背叛/死亡
- 有前世知识作为武器
- 有明确的遗憾修复清单
- 外表与前世相同，内心已是不同的人

**成长轨迹**
```
重生 → 确认已回到过去 → 制定计划 → 小心执行 → 前世伤害出现 → 用新力量应对 → 超越前世最高点
```

**陷阱**（需要避免的设计错误）
- 信息差无限（主角知道所有未来）
- 没有新威胁（前世知识可以解决一切）
- 感情线只是附属品

---

### 隐藏强者型（玄幻/都市常见）

**核心特征**
- 真实实力远超表现
- 主动或被迫隐藏实力
- 在看似平静的状态下保持对局势的掌控

**设计原则**
- 隐藏实力要有合理动机
- 不能一直隐藏（要有揭露时刻）
- 揭露方式要有设计感

---

## 反派原型

### 傲慢强者型

**特征**：强大、自信、有真实的成就支撑傲慢
**问题设计**：傲慢让他低估对手，无法理解弱者的视角
**结局设计**：在他最意想不到的地方被击败
**关键**：傲慢要有逻辑依据，不能只是"坏人所以傲慢"

---

### 背叛者型

**特征**：曾经是盟友/朋友/家人，出于某种原因倒戈
**动机设计**（必须可信）：
- 外部压力（威胁家人）
- 利益驱动（获得远大于忠诚的利益）
- 理念分歧（真心相信对方是错的）
- 长期积累的怨恨（有铺垫）

**错误设计**：毫无理由的突然背叛

---

### 幕后黑手型

**特征**：长期在幕后操纵，真实身份是意外
**设计原则**：
- 真实身份揭露要有前期暗示
- 动机要有深度（不只是"想要权力"）
- 他的行动在揭露后可以重新解读前文

---

## 配角原型

### 忠实助手型

**陷阱**：沦为"是的，主公"机器
**解决**：给他自己的目标、秘密、观点

### 竞争对手型（同辈强者）

**功能**：作为主角成长的参照系
**设计**：要有自己的弧线，不只是主角的跑分标准

### 爱情线辅助型

**陷阱**：只负责推进感情线
**解决**：在感情线之外有独立的生活内容

---

## 人物声音区分

| 类型 | 说话特征 |
|------|---------|
| 傲慢强者 | 短句、命令式、不解释 |
| 智谋型 | 问句多、说半句、话里有话 |
| 热血少年 | 直白、感情外露、少修辞 |
| 腹黑型 | 表面温和、每句话都有第二层意思 |
| 老成型 | 用典、说话留余地、不轻易承诺 |
| 天真型 | 问题多、直接说出所想、不懂暗示 |
